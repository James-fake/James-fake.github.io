MarkCraft — 用户手册

欢迎使用 MarkCraft！本手册将详细介绍编辑器的所有功能，帮助您快速上手并高效使用。

1. 界面布局

编辑器界面由以下几个区域组成：

区域 位置 功能
文件列表 左侧 管理文件夹和文档，支持创建、重命名、删除、折叠
编辑区 中间 Markdown 文本编辑，支持语法高亮、行号、自动补全
预览区 右侧 实时渲染 Markdown 内容，与编辑区滚动同步
大纲导航 最右侧 显示文档标题结构，点击可快速跳转
脚注面板 右下角 显示文档中的脚注列表，点击可跳转
工具栏 编辑区顶部 提供格式化、文件操作、模式切换等快捷按钮
状态栏 编辑区底部 显示字数、字符数、行数和 Lint 警告信息

💡 您可以通过侧边栏的切换按钮来显示或隐藏文件列表和大纲导航，也可以通过工具栏的"关闭预览"按钮切换纯编辑模式。

2. 文件管理

2.1 创建文件

  1. 点击文件列表顶部的 📄 按钮，或右键文件夹选择"新建文件"

  2. 在弹出的对话框中输入文件名

  3. 选择目标文件夹

  4. 点击"确认创建"即可

2.2 创建文件夹

  1. 点击文件列表顶部的 📁 按钮，或右键文件夹选择"新建文件夹"

  2. 输入文件夹名称并确认

2.3 文件操作

  • 打开文件：单击文件列表中的文件

  • 重命名：右键文件或文件夹，选择"重命名"

  • 删除：右键文件或文件夹，选择"删除"

  • 多标签页：打开多个文件时，顶部标签栏可快速切换

  • 文件夹折叠：点击文件夹左侧的箭头可折叠/展开

2.4 另存为

点击工具栏的"另存为"按钮，可将当前文档保存为 .md 文件到本地磁盘。

2.5 快速打开

按 Ctrl+P 可打开快速搜索面板，输入文件名快速定位并打开文件。

2.6 全局搜索

按 Ctrl+Shift+F 可打开全局搜索面板，在所有文件中搜索关键词。

3. 文本编辑基础

3.1 编辑操作

编辑区是一个功能完整的文本编辑器，支持：

  • 常规文本输入和编辑

  • 鼠标选中文本进行操作

  • 拖拽图片直接插入

  • 行号显示，方便定位

  • 实时 Lint 检查，标记语法问题

3.2 撤销与重做

操作 快捷键 说明
撤销 Ctrl+Z 撤销上一步编辑操作
重做 Ctrl+Y 重做已撤销的操作
重做（Mac） Ctrl+Shift+Z Mac 风格的重做快捷键

💡 编辑器基于操作分组的历史栈，最多记录 100 步操作历史。

3.3 查找与替换

操作 快捷键 说明
查找 Ctrl+F 打开搜索栏，输入关键词查找
替换 Ctrl+Shift+H 打开替换栏，支持批量替换

4. 格式化功能

工具栏提供了丰富的格式化按钮，也可以使用快捷键快速操作。

4.1 标题

点击工具栏的标题按钮，或在行首输入 # 加空格：

`markdown

一级标题

二级标题

三级标题

四级标题

五级标题
六级标题

`

💡 多次点击标题按钮可循环切换标题级别（H1 → H2 → ... → H6 → 取消标题）。

4.2 文本样式

样式 快捷键 Markdown 语法 效果
加粗 Ctrl+B 文本 文本
斜体 Ctrl+I 文本 文本
行内代码 — \代码`` 代码

4.3 列表

  • 无序列表*：点击工具栏按钮或在行首输入 -

`markdown

  • 项目一

  • 项目二

    • 子项目
      `

  • 有序列表*：点击工具栏按钮或在行首输入 1.

`markdown

  1. 第一步

  2. 第二步

  3. 第三步
    `

  • 任务列表*：点击工具栏的任务列表按钮

`markdown

  • 已完成

  • 待完成
    `

💡 按 Ctrl+Enter 可快速勾选/取消勾选任务列表项。

  • 缩进与反缩进*：点击工具栏列表菜单中的缩进/反缩进按钮，或使用 Tab / Shift+Tab。

4.4 引用

点击工具栏的引用按钮，或在行首输入 > ：

`markdown

这是一段引用文字
可以跨越多行
`

4.5 代码块

点击工具栏的代码块按钮，选择编程语言：

`markdown
`javascript
function hello() {
console.log("Hello, World!");
}
`
`

支持的语言包括：JavaScript、TypeScript、Python、Java、C/C++、C#、Go、Rust、Ruby、PHP、Swift、Kotlin、SQL、Shell/Bash、HTML、CSS、JSON、YAML、XML、Markdown 等。

💡 快捷键 Ctrl+Shift+K 可快速插入代码块。插入后光标自动定位在代码块内，可直接输入代码。

4.6 水平分割线

点击工具栏的水平线按钮，或输入 ---：

`markdown

`

4.7 链接

点击工具栏的链接按钮，或使用以下语法：

`markdown
链接文字
`

4.8 表格

点击工具栏的表格按钮，可快速插入表格：

`markdown

列1 列2 列3
内容 内容 内容
`

💡 表格编辑器支持可视化操作，可设置行列数后一键插入。

4.9 特殊符号

点击工具栏的 😊 按钮，打开特殊符号选择器，点击即可插入表情符号或特殊字符。

4.10 思维导图

点击工具栏的 📊 按钮，插入 Mermaid 思维导图：

`markdown
`mermaid
mindmap
root((中心主题))
子主题1
子主题2
孙主题1
孙主题2
`
`

💡 编辑器支持 Mermaid 语法，可渲染思维导图、流程图、时序图等多种图表。

4.11 脚注

点击工具栏的脚注按钮，或按 Ctrl+Shift+N 插入脚注：

`markdown
这是一段文字[^1]^

``
[2]:
`

💡 脚注内容会自动在文档底部生成，右侧脚注面板可快速查看和跳转。

4.12 数学公式

行内公式：点击工具栏的 ƒ(x) 按钮，或按 Ctrl+M

`markdown
行内公式 示例
`

块级公式：点击工具栏的 ∫ 按钮，或按 Ctrl+Shift+M

`markdown

`

💡 公式编辑器提供常用模板（分数、根号、积分、求和等），点击即可插入。

5. 自动补全

编辑器内置 8 种智能自动补全功能，大幅提升编写效率：

功能 触发方式 说明
标题自动空格 输入 # 自动在标题标记后添加空格
粗体自动闭合 输入 * 输入 时自动补全闭合
链接自动补全 输入 [ 自动补全链接语法 文字
代码围栏补全 输入 ` 自动补全闭合代码围栏并换行
代码块智能换行 在代码块内按 Enter 自动保持缩进，末行 ` 前自动退出
任务列表切换 Ctrl+Enter 快速勾选/取消勾选任务项
表格自动补全 在表格行末按 Enter 自动补全下一行的表格分隔符
智能退格 在空列表项按 Backspace 自动清除列表标记符

开关控制

点击工具栏右侧的「补全」按钮可开关自动补全功能：

  • 开启状态：按钮蓝色高亮，所有自动补全功能生效

  • 关闭状态：按钮灰色，自动补全功能禁用（基础括号配对仍保留）

  • 开关状态会自动保存，刷新页面后保持

💡 关闭自动补全后，基础的括号配对（()、{}、[]、""、''）和列表/引用续行仍然正常工作。

6. 专注模式与打字机模式

6.1 专注模式

点击工具栏的「专注」按钮，或按 Ctrl+Shift+F 开启专注模式：

  • 隐藏侧边栏、大纲和预览区，只保留编辑区

  • 当前行高亮显示，非当前行淡出

  • 顶部显示专注模式控制栏，可切换打字机模式或退出

6.2 打字机模式

点击工具栏的「打字机」按钮，或按 Ctrl+Shift+T 开启打字机模式：`

  • 光标所在行始终保持在屏幕中央

  • 当前行高亮显示

  • 可与专注模式同时使用

💡 专注模式和打字机模式的状态会自动保存，刷新页面后保持。

7. 高级功能

7.1 实时预览

编辑区的内容会实时渲染到预览区，支持：

  • 滚动同步：编辑区和预览区滚动位置自动同步

  • 大纲联动：预览区当前可见标题在大纲中高亮显示

  • 预览切换：点击工具栏"关闭预览/打开预览"按钮切换

  • 代码块操作：预览区代码块支持复制和展开/折叠

  • 图表渲染：支持 Mermaid 思维导图、流程图等图表实时渲染

  • 数学公式：支持 KaTeX 渲染行内和块级数学公式

7.2 大纲导航

大纲面板显示文档的标题结构：

  • 点击标题可快速跳转到对应位置

  • 当前可见标题会自动高亮

  • 点击右侧切换按钮可显示/隐藏大纲

7.3 脚注面板

脚注面板显示在右下角，列出文档中的所有脚注：

  • 点击脚注可跳转到预览区对应位置

  • 脚注引用和定义之间可双向跳转

7.4 Lint 检查

编辑器会实时检查 Markdown 语法问题：

  • 状态栏显示错误和警告数量

  • 鼠标悬停在状态栏的错误/警告图标上可查看详情

  • 支持一键修复部分语法问题

7.5 自动保存

编辑器会自动保存您的内容：

  • 每次编辑后自动保存到浏览器本地存储

  • 刷新页面后内容不会丢失

  • 关闭浏览器后重新打开，数据依然保留

7.6 图片功能

支持以下方式插入图片：

  • 点击工具栏的"上传图片"按钮选择本地图片

  • 直接拖拽图片到编辑区

  • 粘贴剪贴板中的图片（Ctrl+V）

  • 支持 JPG、PNG、GIF、WebP、BMP、SVG 格式

  • 图片大小限制为 2MB，超出会弹出确认提示

图片优化：点击工具栏的"优化图片"按钮，可将文档中的 Base64 图片转换为本地文件，减小文档体积。

7.7 主题切换

编辑器支持深色和浅色两种主题：

  • 在欢迎界面或预览区顶部点击主题切换按钮

  • 主题偏好会自动保存

7.8 文章元信息（Front Matter）

点击工具栏的"文章元信息"按钮，可编辑文档的 Front Matter 信息：

  • 支持可视化编辑标题、标签、日期等元信息

  • 自动生成和更新 YAML 格式的 Front Matter

7.9 博客工作室

点击主页的"博客工作室"入口，可将 Markdown 文档生成为个人博客：

  • 提供 9 种精心设计的博客风格

  • 支持自定义布局、配色、字体等设计选项

  • 可选择/排除要包含的文档

  • 实时预览博客效果

  • 一键导出为独立 HTML 文件

9. 常见问题

Q: 编辑的内容会丢失吗？

不会。编辑器会自动将内容保存到浏览器本地存储，刷新页面或关闭浏览器后重新打开，内容都会保留。

Q: 如何在文件夹之间移动文件？

目前可以通过以下方式：先在目标文件夹中创建新文件，然后将原文件内容复制过去，最后删除原文件。

Q: 支持哪些 Markdown 语法？

编辑器支持标准 Markdown 语法（GFM），包括标题、加粗、斜体、列表、代码块、引用、表格、链接、图片、水平线、脚注、数学公式等，还支持 Mermaid 思维导图和流程图。

Q: 预览区可以编辑吗？

预览区主要用于查看渲染效果，不支持直接编辑。请在左侧编辑区修改内容，预览区会自动更新。

Q: 如何切换深色/浅色主题？

在欢迎界面或预览区顶部找到主题切换按钮（☀️/🌙），点击即可切换。

Q: 自动补全功能可以关闭吗？

可以。点击工具栏右侧的「补全」按钮即可开关自动补全功能。关闭后，8 种智能补全将不再生效，但基础括号配对仍保留。

Q: 专注模式和打字机模式有什么区别？

专注模式隐藏侧边栏、大纲和预览区，只保留编辑区，让您集中注意力写作。打字机模式让光标所在行始终保持在屏幕中央，模拟打字机的滚动体验。两者可以同时使用。

Q: 图片太大怎么办？

如果图片超过 2MB，编辑器会弹出确认提示。您可以使用"优化图片"功能将 Base64 图片转换为本地文件，减小文档体积。
