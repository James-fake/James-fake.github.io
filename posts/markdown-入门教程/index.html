Markdown 入门教程

欢迎来到 Markdown 的世界！🎉

Markdown 是一种轻量级标记语言，让您用简单的符号就能写出格式优美的文档。本教程将带您从零开始，一步步掌握 Markdown 的核心语法。

💡 MarkCraft 编辑器内置了智能自动补全功能，输入特殊符号时会自动帮您补全格式，让学习 Markdown 更加轻松！

第一章：什么是 Markdown？

Markdown 由约翰·格鲁伯（John Gruber）于 2004 年创建，它的设计理念是：

让文档易读易写，同时可以转换为 HTML 等格式。

为什么学习 Markdown？

  • ✍️ 简单易学：只需记住几个符号就能写出漂亮的文档

  • 📝 专注内容：不用分心调整格式，专注于写作本身

  • 🌍 广泛使用：GitHub、博客、文档、笔记等场景都在用

  • 🔄 通用兼容：纯文本格式，任何编辑器都能打开

第二章：标题

在行首添加 # 号即可创建标题，# 的数量代表标题级别：

`markdown

一级标题（最大）

二级标题

三级标题

四级标题

五级标题

六级标题（最小）

`

💡 通常一篇文章只用一次一级标题，作为文章标题。正文从二级标题开始。

📌 在 MarkCraft 中，输入 # 后会自动添加空格，让标题格式更加规范。

  • 小技巧*：还可以用 === 和 --- 来创建一级和二级标题：

`markdown
这是一级标题

这是二级标题

`

第三章：段落与换行

  1. 1 段落

在 Markdown 中，一个空行分隔两个段落：

`markdown
这是第一段。

这是第二段。
`

  1. 2 换行

在行尾加两个空格再回车，或者在行尾加 <br>，可以实现换行：

`markdown
第一行
第二行
`

⚠️ 注意：只按回车不会换行，两行文字会被合并为一行。

第四章：文本样式

  1. 1 加粗

用两个 * 或 _ 包围文字：

`markdown
**这是加粗文字**
__这也是加粗文字__
`

效果：这是加粗文字

  1. 2 斜体

用一个 * 或 _ 包围文字：

`markdown
_这是斜体文字_
_这也是斜体文字_
`

效果：这是斜体文字

4.3 加粗 + 斜体

组合使用三个 *：

`markdown
**_加粗且斜体_**
`

效果：加粗且斜体

4.4 删除线

用两个 `~` 包围文字：

`` ` ``markdown  
~~这是删除线~~  
`` ` ``

效果：~~这是删除线~~

4.5 行内代码

用反引号 \` 包围代码：

`` ` ``markdown  
使用 `console.log()` 输出信息  
`` ` ``

效果：使用 `console.log()` 输出信息

📌 在 MarkCraft 中，输入 `**` 时会自动补全闭合的 `**`，输入 `[` 会自动补全链接语法，非常方便！

第五章：列表

5.1 无序列表

用 `-`、`*` 或 `+` 加空格：

`` ` ``markdown

-   苹果
    
-   香蕉
    
-   橙子  
    `` ` ``
    

效果：

-   苹果
    
-   香蕉
    
-   橙子
    

5.2 有序列表

用数字加点加空格：

`` ` ``markdown

1.  打开编辑器
    
2.  编写内容
    
3.  保存文件  
    `` ` ``
    

效果：

1.  打开编辑器
    
2.  编写内容
    
3.  保存文件
    

5.3 嵌套列表

用缩进（2 或 4 个空格）创建子列表：

`` ` ``markdown

-   水果
    
    -   苹果
        
    -   香蕉
        
-   蔬菜
    
    -   西红柿
        
    -   黄瓜  
        `` ` ``
        

效果：

-   水果
    
    -   苹果
        
    -   香蕉
        
-   蔬菜
    
    -   西红柿
        
    -   黄瓜
        

📌 在 MarkCraft 中，按 Enter 键会自动续行列表，按 Tab 可缩进，按 Shift+Tab 可反缩进。在空列表项上按 Backspace 会自动清除列表标记。

5.4 任务列表

用 `[ ]` 和 `[x]` 创建待办事项：

`` ` ``markdown

-   学习 Markdown 基础语法

-   完成练习  
    `` ` ``
    

效果：

-   学习 Markdown 基础语法
    
-   了解标题和段落
    
-   学习高级语法
    
-   完成练习

第六章：链接与图片

6.1 链接

`` ` ``markdown

`` ` ``

`` ` ``markdown

6.2 图片

图片语法和链接类似，只需在前面加 `!`：

`` ` ``markdown

第十一章：脚注

脚注可以为文档添加补充说明，不会打断正文的阅读流畅性：

`` ` ``markdown  
这是一段需要注释的文字[^1]，也可以有多处引用[^2]。

`` ` ``

效果：

-   正文中的 `[^1]` 会变成可点击的上标链接
    
-   脚注内容会自动在文档底部渲染
    
-   点击脚注标记可在正文和脚注之间跳转
    

📌 在 MarkCraft 中，点击工具栏的脚注按钮或按 `Ctrl+Shift+N` 可快速插入脚注，右侧脚注面板可查看所有脚注。

14.2 写作建议

-   📌 **先写内容，再调格式**：Markdown 的优势就是专注内容
    
-   📌 **善用标题层级**：保持 H1 → H2 → H3 的逻辑结构
    
-   📌 **代码用代码块**：不要用截图，代码块可以复制
    
-   📌 **表格不宜太宽**：列太多会影响阅读体验
    
-   📌 **预览确认效果**：写完后切换到预览模式检查
    

14.3 MarkCraft 编辑技巧

-   ⚡ **善用自动补全**：输入特殊符号时编辑器会自动补全格式，大幅提升效率
    
-   ⚡ **专注模式写作**：按 `Ctrl+Shift+F` 进入专注模式，排除干扰集中写作
    
-   ⚡ **打字机模式**：按 `Ctrl+Shift+T` 开启打字机模式，光标始终居中
    
-   ⚡ **快捷键加速**：`Ctrl+B` 加粗、`Ctrl+I` 斜体、`Ctrl+Shift+K` 代码块`
    
-   ⚡ **大纲导航**：右侧大纲面板可快速跳转到任意标题
    
-   ⚡ **拖拽插入图片**：直接拖拽图片文件到编辑区即可插入
    
-   ⚡ **关闭自动补全**：如果觉得自动补全干扰，点击工具栏「补全」按钮即可关闭
    

14.4 常见问题

**Q: 空行不生效怎么办？**

确保段落之间有一个完全空白的行（没有任何空格）。

**Q: 列表项之间有空隙怎么办？**

列表项之间不要加空行，连续写就不会有额外间距。

**Q: 代码块里的反引号怎么写？**

用更多数量的反引号包围，例如用四个反引号包围含三个反引号的内容。

**Q: 表格太复杂写不好怎么办？**

先用简单的格式写，再逐步调整对齐。也可以使用 MarkCraft 的可视化表格编辑器一键插入。

**Q: 自动补全太烦人怎么办？**

点击工具栏右侧的「补全」按钮即可关闭自动补全功能。
