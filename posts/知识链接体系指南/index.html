知识链接体系指南

MarkCraft 的知识链接体系让您可以在笔记之间建立联系，将零散的知识编织成网络。本指南将带您了解并实践所有知识链接功能。

一、什么是知识链接？

知识链接是一种将笔记相互关联的方式。当您的笔记越来越多时，传统的文件夹分类已经不够用了——一条笔记可能同时属于多个主题。知识链接让您：

  • 📎 双向链接：在 A 笔记中链接 B，在 B 笔记中也能看到 A 的引用

  • 🔍 反向链接：自动发现哪些笔记引用了当前笔记

  • 🕸️ 知识图谱：以可视化图形展示所有笔记的关联关系

  • 📎 嵌入内容：在当前笔记中直接展示另一个笔记的内容

  • 💡 未链接提及：发现潜在的关联——其他笔记提到了当前笔记的名称但尚未建立链接

二、WikiLink 双向链接

2.1 基本语法

使用双方括号 <a data-wiki-link data-wiki-target="文件名">文件名</a> 创建链接：

makefile今天学习了 <a data-wiki-link data-wiki-target="JavaScript基础">JavaScript基础</a>，和 <a data-wiki-link data-wiki-target="CSS布局">CSS布局</a> 配合使用。

  • 链接目标是不带 .md 扩展名的文件名

  • 输入 <a data-wiki-link data-wiki-target=" 后会自动弹出文件搜索弹窗

  • 在所见即所得模式中，链接会显示为蓝色可点击文字

  • 链接目标不存在时，显示为红色虚线样式（broken link）

2.2 带标签的链接

使用 [[目标" data-wiki-label="显示文字">显示文字</a> 语法，可以自定义链接的显示文字：

markdown我正在学习 <a data-wiki-link data-wiki-target="JavaScript基础" data-wiki-label="JS">JS</a>，很有趣。

这样在文中显示的是"JS"，但点击后跳转到"JavaScript基础"这个笔记。

2.3 导航跳转

在所见即所得模式中，按住 Ctrl（Mac 上 Cmd）并点击链接，即可跳转到目标笔记。

三、链接自动补全

3.1 如何使用

在编辑器中输入 <a data-wiki-link data-wiki-target=" 后，会自动弹出文件搜索弹窗：

  1. 输入 [[ — 弹窗出现，列出所有文件

  2. 继续输入关键词 — 实时过滤匹配的文件

  3. 使用 ↑ ↓ 箭头键选择文件

  4. 按 Enter 确认选中，或 Escape 取消

3.2 试一试

在本文件中试试：输入 [[用户 看看是否能搜到"用户手册"。

  • 目标文件的名称和路径

  • 目标文件的前几行内容摘要

这样无需跳转就能快速了解链接目标的内容。

五、反向链接面板

5.1 什么是反向链接？

反向链接显示哪些其他笔记链接到了当前笔记。这是知识管理的核心功能——当您打开一个笔记时，可以立即看到所有引用它的笔记。

5.2 如何查看

反向链接面板位于侧边栏底部，打开任意文件后即可看到。面板包含两个区域：

  • 反向链接：明确使用 <a data-wiki-link data-wiki-target="当前文件名">当前文件名</a> 链接到当前文件的其他笔记

  • 未链接提及：在其他笔记的正文中提到了当前文件名，但尚未建立 <a data-wiki-link data-wiki-target="...">...</a> 链接

5.3 试一试

为了体验反向链接，让我们创建一些互相链接的笔记：

  • 第一步*：创建一个新文件，命名为 知识链接体验-A.md，写入以下内容：
markdown# 笔记 A

这是笔记 A 的内容。我正在研究 <a data-wiki-link data-wiki-target="知识链接体验-B">知识链接体验-B</a> 和 <a data-wiki-link data-wiki-target="知识链接体系指南">知识链接体系指南</a>。
  • 第二步*：创建另一个文件，命名为 知识链接体验-B.md，写入以下内容：
markdown# 笔记 B

这是笔记 B 的内容。我也参考了 <a data-wiki-link data-wiki-target="知识链接体验-A">知识链接体验-A</a>。

另外，知识链接体系指南是一个很好的入门文档。（这行是未链接提及）

  • 第三步*：回到本文档（知识链接体系指南），查看侧边栏的反向链接面板，您应该能看到：

  • 反向链接：笔记 A 和笔记 B 都链接了本文档

  • 未链接提及：笔记 B 中提到了"知识链接体系指南"但未用双方括号链接

六、嵌入内容

6.1 基本语法

使用 <div data-embed="true" data-embed-target="文件名" data-embed-type="note"></div> 可以将另一个笔记的内容直接嵌入到当前笔记中：

markdown# 我的项目总结

以下是项目需求：

<div data-embed="true" data-embed-target="项目需求" data-embed-type="note"></div>

以上是嵌入的内容。

嵌入的内容会在当前笔记中以内联卡片形式展示，无需跳转即可查看。

七、知识图谱

7.1 什么是知识图谱？

知识图谱以力导向图的方式可视化所有笔记之间的链接关系：

  • 每个节点代表一个笔记文件

  • 节点之间的连线代表链接关系

  • 有链接的节点互相靠近，没有链接的互相远离

7.2 如何打开

有三种方式打开知识图谱：

  1. 快捷键：按 Ctrl+Shift+G

  2. 侧边栏按钮：点击侧边栏底部的"知识图谱"按钮

  3. 图谱会以全屏弹窗形式展示

7.3 图谱交互

操作 方法
平移画布 鼠标拖拽空白区域
缩放 鼠标滚轮
拖拽节点 鼠标拖拽节点
高亮关联 鼠标悬停在节点上
打开文件 点击节点
切换全局/局部 点击顶部的"全局图谱"/"局部图谱"按钮
调整局部深度 拖动深度滑块（1-3）

7.4 全局图谱 vs 局部图谱

  • 全局图谱：显示所有文件及其关联

  • 局部图谱：以当前打开的文件为中心，只显示指定深度内的关联文件

八、实战练习

以下是一个完整的练习流程，帮助您体验所有知识链接功能：

练习 1：创建链接网络

创建三个文件，互相链接：

文件1: 编程语言.md → 链接 <a data-wiki-link data-wiki-target="Python">Python</a>、<a data-wiki-link data-wiki-target="JavaScript">JavaScript</a>
文件2: Python.md → 链接 <a data-wiki-link data-wiki-target="编程语言">编程语言</a>、<a data-wiki-link data-wiki-target="JavaScript">JavaScript</a>
文件3: JavaScript.md → 链接 <a data-wiki-link data-wiki-target="编程语言">编程语言</a>、<a data-wiki-link data-wiki-target="Python">Python</a>

练习 2：验证反向链接

  1. 打开 编程语言.md

  2. 查看侧边栏反向链接面板

  3. 确认 Python.md 和 JavaScript.md 出现在反向链接列表中

练习 3：查看知识图谱

  1. 按 Ctrl+Shift+G 打开知识图谱

  2. 观察三个节点之间的连线

  3. 悬停节点查看高亮效果

  4. 点击节点跳转到对应文件

练习 4：体验嵌入内容

  1. 创建 每日总结.md

  2. 在其中使用 <div data-embed="true" data-embed-target="编程语言" data-embed-type="note"></div> 嵌入内容

  3. 观察嵌入效果

练习 5：发现未链接提及

  1. 在任意文件中写一段包含"编程语言"文字的内容（不加双方括号）

  2. 打开 编程语言.md

  3. 在反向链接面板的"未链接提及"区域找到该引用

  4. 点击将其转化为正式链接

十、常见问题

Q: 链接目标必须存在吗？

不是。如果链接目标不存在，链接会显示为红色虚线样式（broken link），提醒您该文件尚未创建。这是知识管理中常见的"先建链接后建文件"工作流。

Q: 链接目标带路径吗？

目前 WikiLink 只支持文件名匹配（不带路径），所以请确保文件名唯一。如果有重名文件，会匹配索引中第一个找到的文件。

Q: 反向链接是实时的吗？

是的。当您在笔记 A 中添加或删除对笔记 B 的链接时，笔记 B 的反向链接面板会实时更新。

Q: 嵌入内容可以编辑吗？

嵌入的内容是只读预览。如需编辑，请直接打开源文件进行修改。

Q: 知识图谱支持多少个节点？

图谱最多支持 300 个节点。超过 300 个文件时，只显示前 300 个。
